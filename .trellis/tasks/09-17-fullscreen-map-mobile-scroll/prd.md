# 优化技能树全屏地图与手机滚动

## Goal

让技能树在桌面和手机上都清晰可读。

让用户可以进入全屏地图模式。

消除手机页面的横向滑动困扰。

保持现有学习功能和存档格式不变。

## Confirmed Facts

- 页面根节点在手机宽度 390px 时没有横向溢出。
- 地图容器 `#viewport` 使用 `overflow:auto`。
- 手机地图内部宽度约为 707px，视口宽度约为 390px。
- 手机横向滑动来自地图内部，不是页面根节点。
- 当前 `MAP_W` 为 982px，节点基础尺寸为 160×88px。
- 桌面两侧面板打开时，中间地图区域宽度约为 740px。
- 当前页面没有全屏地图模式。

## Requirements

### R1. 全屏地图模式

- 增加明确的地图全屏入口。
- 全屏模式让地图区域占满当前视口。
- 全屏模式保留缩放、定位、搜索和节点选择。
- 全屏模式提供明确的退出入口。
- 全屏状态只存在当前页面会话，不写入 `localStorage`。

### R2. 技能树可读性

- 增大技能节点的实际显示尺寸。
- 减少面板和装饰内容对地图空间的占用。
- 全屏模式优先显示当前节点及其关联路径。
- 保持节点连接关系和地图内部纵向浏览能力。

### R3. 手机滚动边界

- 页面根节点禁止横向滚动。
- 手机默认不让用户横向拖动整个页面。
- 地图内容必须采用明确的移动端浏览方式。
- 移动端主要浏览方向应为纵向。
- 不能因此删除其他分支、搜索、章节定位或节点选择能力。

### R4. 功能兼容

- 不修改技能树数据和解锁规则。
- 不修改任务、笔记、日志、导入、导出、演示和撤销逻辑。
- 不修改 `localStorage` 存档结构。
- 不引入第三方依赖和网络请求。

### R5. 教材显示筛选

- 在技能地图提供教材显示筛选入口。
- 支持单独显示或隐藏铃木教程节点。
- 支持单独显示或隐藏练习曲节点。
- 练习曲节点包含沃尔法特、开塞、马扎斯、小顿特等课程。
- 筛选只改变地图显示，不改变节点数据、解锁规则和教材页内容。
- 默认显示全部教材。
- 筛选状态只存在当前页面会话，不写入学习存档。

### R6. 用户体验与可访问性

- 全屏入口提供可读的文本或 `aria-label`。
- 全屏入口支持键盘操作。
- 全屏状态支持 Escape 退出。
- 关闭的面板不能进入键盘焦点顺序。
- 继续尊重 `prefers-reduced-motion`。

## Acceptance Criteria

- [x] 桌面可以进入和退出全屏地图模式。
- [x] 全屏模式下技能树比当前默认模式明显更大。
- [x] 手机页面根节点不产生横向滚动。
- [x] 手机地图不要求用户横向拖动整个页面。
- [x] 手机仍可访问所有分支和节点。
- [x] 手机主要浏览方向为纵向。
- [x] 地图可以分别隐藏或打开铃木教程与练习曲节点。
- [x] 隐藏教材后，技能节点仍可查看和操作。
- [x] 教材筛选不改变学习状态和教材页内容。
- [x] 搜索、章节定位、缩放、定位和节点选择继续工作。
- [x] 三个视图、学习记录和存档行为继续工作。
- [x] 全屏和滚动状态不进入学习存档。
- [x] 通过手机、平板和桌面浏览器回归。

## Out of Scope

- 不重写技能树数据、布局关系和解锁规则。
- 不拆分为前端框架、组件库或多文件应用。
- 不新增浏览器权限、账号、服务端和云同步。
- 不重新设计品牌颜色和核心视觉主题。
- 不把教材显示筛选扩展为存档数据编辑。

## Key Decisions

### 移动端采用分支专注模式

移动端一次展示一个技能分支。

移动端使用较大节点和纵向浏览。

用户通过分支切换器访问其他分支。

搜索、章节定位和教材页继续访问全部分支和节点。

这个方案满足“大节点”和“无横向滑动”。

这个方案不提供五条分支的同时总览。

### 教材筛选只作用于技能地图

地图提供两个独立开关：铃木教程、练习曲。

两个开关默认打开。

开关只改变地图节点的显示。

教材页继续显示完整课程列表。

筛选状态只存在当前页面会话。

筛选状态不进入学习存档。

### 全屏采用页面内模式

全屏入口让地图工作区占满浏览器视口。

实现使用页面内布局状态，不申请浏览器全屏权限。

这样可以保持稳定的退出按钮、键盘行为和移动端兼容性。
