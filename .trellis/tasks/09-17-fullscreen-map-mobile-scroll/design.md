# 设计：全屏技能地图与移动端浏览

## 1. 设计目标

本次改动解决三个直接问题：

1. 中间技能树在桌面默认布局中显示过小。
2. 用户缺少专注查看技能树的全屏入口。
3. 手机地图的多列宽度迫使用户横向拖动。

设计保持现有单文件、原生 HTML/CSS/JavaScript 结构。

设计不修改学习数据、解锁规则和存档格式。

## 2. 当前约束

- 页面使用 `index.html` 承载结构、样式和运行时逻辑。
- 地图使用 `#viewport`、`#mapWorld` 和 SVG 连线。
- 桌面地图保留五个技能分支的并列关系。
- 手机视口约为 390px，现有地图内部宽度约为 707px。
- 现有保存逻辑只应继续保存学习状态 `state`。
- 现有面板已经支持收起、抽屉和 `inert` 焦点隔离。

## 3. 布局模式

### 3.1 桌面默认模式

桌面默认模式保留左侧导航、中央地图和右侧详情。

中央地图使用剩余空间。

节点尺寸适度放大。

地图工具栏保持搜索、章节、路径和操作入口。

### 3.2 移动端分支专注模式

移动端只渲染当前分支的节点。

当前分支由移动端分支切换器决定。

首次进入移动端时，选择当前节点所属分支。

没有当前节点时，默认选择第一个分支。

节点在单列中按阶段纵向排列。

连线只绘制当前分支中可见的端点。

地图默认宽度不超过手机视口。

地图视口允许纵向滚动。

手机根页面和默认地图不产生横向滚动。

用户仍可以通过搜索、教材页和分支切换器访问其他节点。

### 3.3 页面内全屏模式

全屏模式增加 `.app.map-fullscreen` 状态。

全屏状态隐藏导航、顶部栏、详情面板、入门卡片和图例。

地图工具栏和地图操作保留在视口内。

地图工作区占满浏览器视口。

全屏模式重新计算地图宽度和缩放比例。

进入和退出全屏不改变当前节点和学习状态。

全屏状态不写入 `localStorage`。

退出入口同时支持按钮和 Escape。

## 4. 运行时数据流

增加以下运行时变量：

- `mapFullscreen`：页面内全屏状态。
- `mapLane`：当前移动端分支，桌面值为 `all`。
- `mapShowBooks`：是否显示铃木教程节点。
- `mapShowEtudes`：是否显示练习曲节点。

这些变量属于视图状态。

这些变量不放入 `state`。

这些变量不进入 `save()`、导入、导出和撤销记录。

地图渲染通过统一的 `mapNodeVisible(node)` 判断节点：

1. 桌面检查教材开关。
2. 手机再检查当前分支。
3. 技能节点不受教材开关隐藏。

隐藏教材节点不删除原始 `nodes` 数组中的数据。

隐藏教材节点不改变解锁计算。

隐藏教材节点仍可由搜索和教材页选中。

## 5. 布局计算

桌面继续使用现有阶段、列和行关系。

桌面隐藏节点时保留原布局占位。

这样可以避免开关切换后所有技能节点跳动。

移动端增加 `calculateMobileLayout(visibleNodes, width)`。

移动端布局步骤如下：

1. 按现有阶段顺序分组。
2. 在单列中按既有行顺序排序。
3. 为每个节点生成居中的 x 坐标。
4. 为每个阶段记录顶部位置。
5. 只为可见端点生成 SVG 连线。

`applyZoom()` 使用当前地图基础宽度。

`centerNode()` 使用当前布局坐标。

`jumpStage()` 使用当前布局的阶段顶部位置。

手机默认 `fitWidth()` 把地图缩放限制在视口宽度内。

用户主动放大后可以查看节点细节。

主动放大不代表页面根节点获得横向滚动。

## 6. 教材筛选交互

地图操作区增加“筛选地图内容”入口。

入口打开现有模态框系统。

模态框提供两个独立复选框：

- 铃木教程。
- 练习曲（沃尔法特、开塞、马扎斯等）。

用户点击应用后更新运行时变量并重新渲染地图。

用户点击取消后保留原筛选状态。

默认两个复选框都选中。

筛选后仍显示技能节点和技能连线。

地图筛选不影响教材页的完整列表。

## 7. 响应式工具栏

移动端工具栏增加分支选择器。

移动端搜索占据独立整行。

章节选择器和分支选择器共享下一行空间。

定位、添加节点和筛选入口保持可触达。

路径筛选在手机上隐藏或移动到次级操作。

所有主要触控目标保持至少 34px。

## 8. 可访问性和动效

- 全屏、筛选和分支选择器提供中文 `aria-label`。
- 全屏按钮同步 `aria-pressed` 和图标含义。
- 关闭面板保持 `inert` 和 `aria-hidden`。
- 模态框打开后焦点进入模态框。
- Escape 按优先级关闭模态框、退出全屏和关闭面板。
- 继续使用现有 `prefers-reduced-motion` 规则。
- 不用颜色作为教材筛选的唯一含义。

## 9. 风险与回退

### 风险：手机节点与跨分支连线关系变弱

回退措施：保留桌面总览，并让搜索和教材页访问全部节点。

### 风险：筛选后当前节点暂时不可见

回退措施：详情状态继续保留，搜索和教材页可以重新定位。

### 风险：全屏改变现有面板状态

回退措施：全屏只增加 CSS 状态，退出时恢复已有面板状态。

### 风险：缩放导致地图宽度扩大

回退措施：默认适配视口，限制页面根节点横向溢出，保留纵向地图滚动。

| 手机 390px | 搜索、分支切换、教材筛选和节点选择可用 |
| 平板 768px | 面板收起和地图宽度正常 |
| 桌面 1280px | 五分支关系、全屏入口和退出可用 |
| 桌面 1440px | 全屏节点尺寸明显大于默认模式 |
| 键盘 | Tab、Enter、Space、Escape 行为正确 |
| 存档 | 新增视图状态不改变存档内容 |
| 学习 | 三个视图、解锁和记录逻辑无回归 |
