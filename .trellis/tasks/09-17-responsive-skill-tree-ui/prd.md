# 优化小提琴技能树响应式界面

## Goal

改善小提琴技能树在电脑和手机上的阅读、导航与操作体验。

保持现有学习流程、数据结构和存档能力不变。

## Background

- 产品是一个单文件离线页面，主要实现位于 `index.html`。
- 页面包含左侧旅程导航、中间内容区和右侧节点详情。
- 页面包含技能地图、教材与曲目、练习日志三个视图。
- 页面已有移动端导航抽屉和移动端详情抽屉的基础逻辑。
- 页面已有搜索、阶段筛选、路径筛选、地图缩放、节点选择、节点达标、任务记录、笔记、日志、导入、导出、演示和撤销功能。
- 页面使用原生 HTML、CSS 和 JavaScript。
- 页面通过 `localStorage` 保存正式进度。
- 页面必须继续支持离线打开。

## Requirements

### R1. 响应式布局

- 适配常见手机宽度、平板宽度和桌面宽度。
- 保持技能地图的横向与纵向浏览能力。
- 避免标题、按钮、表单和统计信息互相遮挡。
- 在窄屏上保证主要操作具有足够的点击区域。
- 在宽屏上减少无效留白，并保持信息层级清晰。

### R2. 左侧导航收起

- 桌面端允许用户收起和展开左侧导航。
- 收起后仍提供明确的展开入口。
- 收起和展开不改变当前视图、选中节点或进度。
- 手机端继续使用抽屉式导航。
- 打开导航抽屉时提供遮罩，并支持点击遮罩或按 Escape 关闭。

### R3. 右侧详情收起

- 桌面端允许用户收起和展开右侧节点详情。
- 收起后仍提供明确的打开入口。
- 打开详情后不改变当前节点和地图位置。
- 手机端继续使用详情抽屉，且不遮挡抽屉外的交互状态。
- 详情抽屉支持关闭按钮和 Escape 关闭。

### R4. 用户体验

- 为侧栏收起、展开和抽屉状态提供清晰的视觉反馈。
- 为新增的交互控件提供可访问名称、键盘焦点和 Hover 状态。
- 维持现有深色视觉风格、颜色语义和文字语言。
- 尊重 `prefers-reduced-motion` 设置。
- 不新增网络请求，不引入第三方依赖。

### R5. 功能兼容

- 不改变现有节点解锁规则、任务记录规则和存档格式。
- 不改变现有视图切换、搜索、筛选、缩放、导入、导出、演示和撤销行为。
- 不删除现有代码注释。

## Acceptance Criteria

- [x] 在窄屏手机视口中，页面不出现横向页面溢出。
- [x] 在手机视口中，左侧导航和右侧详情可以分别打开与关闭。
- [x] 在桌面视口中，左侧导航和右侧详情可以分别收起与展开。
- [x] 侧栏操作不会丢失当前视图、选中节点、地图缩放和滚动位置。
- [x] 地图、教材与曲目、练习日志三个视图在手机和桌面均可操作。
- [x] 搜索、筛选、缩放、节点达标、任务记录和笔记操作继续生效。
- [x] 导入、导出、演示、撤销和 `localStorage` 存档行为保持兼容。
- [x] 新增控件可通过键盘访问，并具备可读的 `aria-label` 或可见文本。
- [x] `prefers-reduced-motion: reduce` 下不产生必要之外的动画。
- [x] 页面通过项目要求的构建、测试编译和静态分析检查。

## Out of Scope

- 不重写技能树数据、节点解锁规则或存档校验逻辑。
- 不拆分为前端框架、组件库或多文件应用。
- 不新增账号、云同步、服务端接口或网络资源。
- 不重新设计品牌、文案和核心视觉主题。

## Key Decisions

- 桌面端左右侧栏独立收起。
- 桌面端收起状态只在当前页面会话中保留。
- 刷新页面后恢复默认布局，不写入 `localStorage`。
- 手机端继续使用抽屉式导航和详情面板。

## Technical Notes

- 优先扩展现有 CSS 断点和原生事件绑定。
- 侧栏状态属于界面状态，不属于学习进度状态。
- 新增状态不得进入 `validateState`、导入导出或存档结构。
