## 风险与回滚点

- CSS 修改集中在现有布局选择器和媒体查询中。
- JavaScript 修改集中在 `closeMobileNav`、`wireEvents` 和新增布局辅助函数附近。
- 如果桌面端 Grid 收起影响主区域尺寸，先回滚 Grid 轨道规则，再保留抽屉逻辑。
- 如果详情状态影响移动端抽屉，先回滚桌面端隐藏规则，再保留现有 `.detail.open` 行为。
- 不使用破坏性 Git 命令，不重置用户已有改动。
